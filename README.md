# Tienda Panther

Fork single-tenant de la tienda pública. Su `username` y rutas de entrada están fijados en este proyecto; no recibe cambios de `web/` automáticamente.

Usar [`../AGENTS.md`](../AGENTS.md) para el modelo compartido y validar únicamente este package cuando la tarea sea específica del clon.

```bash
bun install
bun run dev
bun run build
bun run lint
```
